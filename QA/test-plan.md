### FR-A01: 매장 인증

> **BE 현황 (2026-04-08)**: 현재 JWT 만료 = **1시간** (3600000ms), 비밀번호 **평문 비교** (하드코딩), 로그인 시도 제한 **미구현**
> 16시간 세션, bcrypt, 시도 제한은 추후 DB 연동 시 구현 예정

| ID | 테스트 시나리오 | 수용 기준 | 결과 |

## 5. 통합 테스트 시나리오

### IT-01: 고객 주문 전체 플로우
```
테이블 로그인 → 메뉴 조회 → 장바구니 추가 → 주문 확정 
→ 주문 성공(5초 리다이렉트) → 인구통계 수집 → 별점 평가 
→ 주문 내역 확인 → 관리자 대시보드에 실시간 표시
```

| 단계 | 확인 사항 |
|---|---|
| 1. 테이블 로그인 | JWT 발급 (storeId, tableId, tableName 반환) |
| 2. 메뉴 조회 | GET /menus — 카테고리별 메뉴 표시, 별점 포함 |
| 3. 장바구니 | 추가/수량 변경/총액 계산 정상 (localStorage) |
| 4. 주문 확정 | POST /orders (tableId, items) → 주문 번호 반환 |
| 5. 주문 성공 | 5초 후 메뉴 화면 리다이렉트, 장바구니 클리어 |
| 6. 인구통계 | POST /recommendations/demographic 성별/나이대 저장 |
| 7. 별점 평가 | POST /ratings 메뉴별 별점 저장 |
| 8. 대시보드 반영 | GET /orders/dashboard에 새 주문 표시 확인 |

### IT-02: 관리자 주문 관리 플로우
```
관리자 로그인 → 대시보드 조회 → 주문 확인 → 주문 삭제 → 과거 내역 확인
```

| 단계 | 확인 사항 |
|---|---|
| 1. 관리자 로그인 | JWT 발급 (현재 1시간) |
| 2. 대시보드 | GET /orders/dashboard — 테이블별 그리드 표시 |
| 3. 주문 상세 | 테이블 클릭 → GET /orders?tableId= → 상세 모달 |
| 4. 주문 삭제 | DELETE /orders/{id} → 대시보드 총액 재계산 |
| 5. 과거 내역 | GET /orders/history?tableId= 조회 가능 |

### IT-03: 메뉴 관리 → 고객 반영 플로우
```
관리자 메뉴 등록(이미지 포함) → 고객 메뉴 화면에서 새 메뉴 확인
→ 메뉴 수정 → 고객 화면 반영 → 메뉴 삭제 → 고객 화면에서 제거
```

### IT-04: 추천 시스템 플로우
```
다수 고객 주문 + 인구통계 수집 → 동일 성별/나이대 추천 모달 
→ 인기 메뉴 추천 정확성 확인 → 데이터 부족 시 전체 인기 폴백
```
